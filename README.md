# رواء | Rawaa

صفحة روابط التواصل الاجتماعي لمتجر رواء، مع باركود QR يفتح الصفحة.
A single-page social links site for Rawaa with a built-in QR code.

## الملفات
- `index.html`: الصفحة كاملة (HTML وCSS وJS في ملف واحد، والشعار مدمج فيه).

## تعديل الروابط
افتح `index.html` وابحث عن الوسوم `<a class="link"` وغيّر قيمة `href` لكل زر.

## النشر على GitHub Pages
Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save.
